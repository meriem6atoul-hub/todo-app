# Todo App
Simple Todo App built with:
- HTML
- CSS
- Vanilla JavaScript

## Features
- Add / delete tasks
- Mark tasks as completed
- Filter tasks: All / Active / Completed
- Edit task
- Task counter
- Data saved in localStorage
